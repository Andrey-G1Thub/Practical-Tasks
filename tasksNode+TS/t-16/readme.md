# t-16 — Notes App

## Задача

Разработать веб-приложение для управления заметками с использованием Node.js, Express и TypeScript.

Приложение должно обеспечивать создание, просмотр, редактирование и удаление заметок с сохранением данных на сервере.

## Требования

### 1. Backend

- Создать сервер на Express.
- Использовать TypeScript.
- Настроить отображение страниц с помощью шаблонизатора EJS.
- Реализовать REST API для работы с заметками.
- Организовать хранение данных в JSON-файле (`db.json`).
- Реализовать получение, создание, редактирование и удаление заметок.
- Использовать уникальные идентификаторы для заметок.
- Обеспечить проверку входящих данных и обработку ошибок.
- Возвращать соответствующие HTTP-статусы и сообщения об ошибках.

### 2. Frontend

- Создать интерфейс приложения с помощью HTML и CSS.
- Использовать TypeScript для клиентской логики.
- Реализовать получение и отображение списка заметок через Fetch API.
- Обеспечить добавление новых заметок без перезагрузки страницы.
- Реализовать редактирование заметок через модальное окно.
- Реализовать удаление заметок без перезагрузки страницы.
- Обеспечить отображение ошибок при некорректных данных и проблемах с сервером.

### 3. Интерфейс

- Создать форму добавления заметок.
- Отображать заметки в виде отдельных карточек.
- Добавить кнопки редактирования и удаления.
- Реализовать модальное окно редактирования с возможностью сохранения и отмены.
- Обеспечить адаптивность интерфейса для мобильных устройств.

### 4. Проверка работоспособности

- Проверить все CRUD-операции.
- Проверить обработку некорректных входных данных.
- Проверить ответы API и HTTP-статусы.
- Проверить обработку ошибок при недоступности сервера.
- Проверить корректность работы интерфейса после выполнения операций.

## Технологии

- Node.js
- Express
- TypeScript
- EJS
- HTML
- CSS
- Fetch API
- JSON
